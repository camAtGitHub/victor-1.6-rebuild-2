# Mapping progress (optional)

Use this folder for **work queues and session notes**, not as the catalog itself.

| File / pattern | Purpose |
|---|---|
| `../consolevarlist_*` | Full robot name inventory (keep complete) |
| `unmapped_8888.txt` | Optional regenerated list of dump ids not yet in `cvcatalog/vars/` |
| `session-YYYY-MM-DD.md` | What you mapped today, what’s next |

**Done** = entry lives in `resources/webserver/cvcatalog/vars/*.json` and is listed in `index.json`.

See `resources/webserver/cvcatalog/AGENTS.md`.
